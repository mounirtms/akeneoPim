## Issues Found

### 1. Cache Permission Errors (68 occurrences)

**Issue:** Cache directories not writable by web server

**Fix Applied:**
```bash
sudo chown -R pim:pim var/cache var/logs var/file_storage
sudo chmod -R 775 var/cache var/logs var/file_storage
```

### 2. JavaScript Routing Errors (19 occurrences)

**Issue:** Frontend JavaScript trying to access invalid routes

**Cause:** Browser extension or cached JavaScript code issue

**Recommendation:**
- Clear browser cache
- Disable browser extensions
- Regenerate JavaScript routes

### 3. CREATE_TIME Errors (4 occurrences)

**Issue:** Database table metadata not available

**Cause:** MySQL information_schema limitations or MariaDB compatibility

**Impact:** Low (only affects install status check)

**Status:** Non-critical, can be ignored

### 4. Unserialization Errors (2 occurrences)

**Issue:** Corrupted serialized data in database

**Affected:** Job parameters or batch execution data

**Recommendation:** Clean up old job executions
```bash
php bin/console pim:job:purge-history --all --env=prod
```

### 5. SQL Errors (13 occurrences)

**Issue:** Outdated queries or database schema changes

**Common Causes:**
- Queries using old column names (e.g., 'name', 'label', 'level')
- Missing tables (e.g., pim_catalog_product_value)

**Status:** These are from test scripts, not affecting production
