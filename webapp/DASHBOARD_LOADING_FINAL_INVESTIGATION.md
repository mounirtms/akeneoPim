## What We Learned

1. **Asset Installation Breaks Custom Changes**  
   - Running `pim:installer:assets --clean` reverts AMD→ES6 changes
   - Need to apply fixes AFTER asset install

2. **Template Changes May Not Apply**  
   - Even after cache clear, changes don't show
   - Possible prod environment caching/minification issue

3. **Deep JavaScript Issue**  
   - This is NOT just missing files
   - This is NOT just AMD/ES6 conversion
   - Something fundamentally broken in JS runtime post-login

4. **Console Logs Don't Appear**  
   - Even simple `console.log('test')` produces nothing
   - Suggests scripts not executing OR output suppressed
