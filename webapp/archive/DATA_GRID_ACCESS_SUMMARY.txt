HOW TO FILTER ECOMMERCE DATA
================================================================================

FILTER BY PRICE:
---------------
1. Click "Filters" button (top-left of product grid)
2. Click "+ Add a filter"
3. Select "price"
4. Choose channel: "ecommerce"
5. Choose currency: DZD
6. Set range: Min [____] Max [____]
7. Click "Apply"

Example: Find products between 50 DZD and 500 DZD
- Min: 50
- Max: 500
- Result: Shows only products in that price range

FILTER BY IMAGES:
----------------
1. Click "Filters" button
2. Click "+ Add a filter"
3. Select "image" (or "thumbnail" or "small_image")
4. Choose operator:
   - "is empty" → Products WITHOUT images
   - "is not empty" → Products WITH images
5. Click "Apply"

Current Image Status:
- Products with images ready: 98.54% (9,399 of 9,538)
- Products missing images: 1.46% (139 products)

FILTER BY DESCRIPTION:
---------------------
1. Click "Filters"
2. Add filter → "description" (or "short_description")
3. Operator: "is empty" / "is not empty"
4. Apply

Current Description Status:
- Products with description: 96.07% (9,163)
- Products missing description: 3.93% (375)

FILTER BY CATEGORY:
------------------
METHOD 1: Use Category Tree (Easiest)
- Simply click any category name in left panel
- Products filter automatically

METHOD 2: Use Filters
1. Click "Filters"
2. Add filter → "categories"
3. Select category from dropdown
4. Check "Include subcategories" if desired
5. Apply

FILTER BY COMPLETENESS:
----------------------
1. Click "Filters"
2. Add filter → "completeness"
3. Configure:
   - Channel: "ecommerce"
   - Locale: "fr_FR" (or en_US, ar_DZ)
   - Operator: = / < / > / ≥ / ≤
   - Value: Percentage (0-100)
4. Apply

Examples:
- "= 100%" → Only COMPLETE products
- "< 100%" → INCOMPLETE products
- "≥ 80%" → At least 80% complete
- "≤ 50%" → Less than 50% complete (needs work)

FILTER BY EAN (BARCODE):
-----------------------
1. Click "Filters"
2. Add filter → "ean"
3. Operator: "is not empty"
4. Apply

FILTER BY WEIGHT:
----------------
1. Click "Filters"
2. Add filter → "weight"
3. Set range or condition
4. Apply

FILTER BY FAMILY:
----------------
1. Click "Filters"
2. Add filter → "family"
3. Select: products, fournitures_bureau, papeterie, etc.
4. Apply

COMBINE MULTIPLE FILTERS:
-------------------------
You can add multiple filters simultaneously:

Example 1: Complete products with images
- Filter 1: completeness ≥ 80% (ecommerce, fr_FR)
- Filter 2: image is not empty
- Filter 3: price > 0

Example 2: Incomplete products needing work
- Filter 1: completeness < 80%
- Filter 2: description is empty
- Filter 3: category = SCOLAIRE

SAVE FILTERS AS VIEWS:
---------------------
After creating complex filters:
1. Click "Views" dropdown
2. Select "Save current view"
3. Give it a name: e.g., "Incomplete SCOLAIRE Products"
4. Click Save
5. Access anytime from Views dropdown

TROUBLESHOOTING
================================================================================

ISSUE: "Product grid is empty / No products showing"
SOLUTION:
1. Check locale selector (top-right) - must be fr_FR, en_US, or ar_DZ
2. Check channel selector (top-right) - select "ecommerce"
3. Clear any active filters - click "Clear all filters"
4. Clear browser cache (Ctrl+Shift+Delete / Cmd+Shift+Delete)
5. Clear Akeneo cache: php bin/console cache:clear --env=prod

ISSUE: "Categories not visible / Category tree empty"
SOLUTION:
1. Expand category tree - click ▶ arrows
2. Check locale is active (fr_FR, en_US, ar_DZ)
3. Some categories ARE empty (31 categories) - this is normal
4. Focus on main categories (SCOLAIRE, LOISIRS, BEAUX ARTS)

ISSUE: "Cannot see product model statistics"
SOLUTION:
1. Go to: Products → Product Models (not Products → Products)
2. Statistics visible in # Variants column
3. Click any model row to see full variant list
4. Run diagnostic: php CHECK_AKENEO_DATA_INSIGHTS.php
