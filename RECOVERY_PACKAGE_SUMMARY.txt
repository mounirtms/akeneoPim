TROUBLESHOOTING QUICK REFERENCE
================================================================================

Problem: Script fails during database restoration
→ Check: Database credentials, MariaDB running on port 3307
→ Solution: Verify backup file not corrupted with `gunzip -t`

Problem: Elasticsearch reindexing fails
→ Check: curl http://localhost:9200
→ Solution: Manually run php bin/console akeneo:elasticsearch:reset-indexes

Problem: Login still doesn't work
→ Check: var/sessions permissions
→ Solution: chmod 755 var/sessions, create new test user

Problem: Products not visible
→ Check: curl localhost:9200/akeneo_pim_product/_count
→ Solution: php bin/console pim:product:index --env=prod

Problem: CSS/JS files return 404
→ Check: .htaccess files exist
→ Solution: php bin/console pim:installer:assets --symlink --clean
